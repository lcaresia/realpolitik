REALPOLITIK: LIVING NATIONS FOR HUMANKIND
=========================================

Gratuit et open source (licence MIT) : github.com/lcaresia/realpolitik

CONFIGURATION REQUISE
- HUMANKIND sous Windows (Steam ou Epic), en solo.
- Internet uniquement pour les fournisseurs d'IA de Realpolitik.

INSTALLER
- Setup : lancez Realpolitik_Setup.exe. Il trouve le jeu et installe BepInEx si besoin.
  Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur « Informations
  complémentaires » -> « Exécuter quand même ».
- Manuel (zip) : fermez le jeu, extrayez le zip DANS le dossier du jeu (celui qui contient
  Humankind.exe) et acceptez de fusionner le dossier BepInEx.

CONFIGURER L'IA
1. Ouvrez le jeu -> menu principal -> Realpolitik.
2. Choisissez un fournisseur d'IA à gauche (le plus simple est OpenRouter : une connexion, sans clé).
   Vous pouvez aussi utiliser une clé d'API (DeepSeek, OpenAI, Gemini...), ChatGPT via
   Codex ou un modèle local (Ollama / LM Studio).
Sans fournisseur, tout le reste fonctionne (monnaie, Banque centrale, péages, 16 empires) et les
nations utilisent l'IA native du jeu.

METTRE À JOUR
Téléchargez la nouvelle version sur github.com/lcaresia/realpolitik/releases et installez-la
par-dessus. Réglages, clés et sauvegardes sont conservés.

DÉSINSTALLER
Paramètres Windows -> Applications -> « Realpolitik: Living Nations for HUMANKIND ».
Le désinstallateur demande s'il faut garder vos réglages et clés. Les sauvegardes ne sont jamais supprimées.

STEAM DECK / LINUX
Utilisez le zip. Dans Steam : HUMANKIND -> Propriétés -> Options de lancement :
  WINEDLLOVERRIDES="winhttp=n,b" %command%

PROBLÈMES
- Le mod ne se charge pas : cherchez « CurrencyMod » et « Núcleo carregado » dans BepInEx\LogOutput.log.
- L'antivirus a supprimé winhttp.dll : restaurez-le (c'est le chargeur de BepInEx) et ajoutez une exception.
- Les sauvegardes de plus de 10 empires ne s'ouvrent qu'avec le mod installé.
- Autre problème : ouvrez une issue sur github.com/lcaresia/realpolitik/issues (joignez
  BepInEx\LogOutput.log).
