Install

Requirements

Windows · HUMANKIND on Steam · single-player. Epic: not tested yet. Mac and Xbox / Game Pass: not supported. Steam Deck: experimental.

1. Download

Right after purchase, the confirmation page shows your license key and the download. Later, get any version on the download page with your key, or from the game: when an update is out, the mod shows it in the main menu with a download button.

2. Copy into the game folder

Unzip into your HUMANKIND folder on Steam (Steam → right-click HUMANKIND → Manage → Browse local files). An installer is in preparation.

If Windows SmartScreen warns about the installer once it ships, choose “More info” → “Run anyway”.

3. Pick your AI

In the main menu, open AI Diplomacy. Sign in with OpenRouter or paste a key (DeepSeek, OpenAI, Gemini, GLM, xAI), set your spending cap, and start a game.

Steam Deck (experimental)

Use the zip install and add the launch option the mod's readme provides. Untested; feedback welcome.

Uninstall

Delete the two mod folders listed in the readme. Your saves keep opening without the mod, except saves with more than 10 empires, which need MoreEmpires.
