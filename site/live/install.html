Install

Requirements

Windows · HUMANKIND on Steam or Epic · single-player. Steam Deck through the manual zip. Mac and Xbox / Game Pass: not supported.

1. Download

Get the latest Realpolitik_Setup.exe for free from GitHub Releases. Every version is listed there, and the source code is at github.com/lcaresia/realpolitik.

2. Run the installer

Close HUMANKIND and run Realpolitik_Setup.exe. It finds the game on Steam or Epic, installs BepInEx if it is missing, and keeps any BepInEx or mods you already have. Your settings, keys and saves are never touched.

Windows may show “Windows protected your PC” for new apps. Click “More info” → “Run anyway”. If Windows blocks it without that option (Smart App Control), use the manual zip below.

3. Pick your AI

Open the game → main menu → Realpolitik. Sign in with OpenRouter or paste a key (DeepSeek, OpenAI, Gemini, GLM, xAI), set your spending cap, and start a game.

Manual zip

Close the game and extract the zip into the HUMANKIND folder (the one with Humankind.exe; on Steam: right-click HUMANKIND → Manage → Browse local files). Accept merging the BepInEx folder.

Steam Deck

Use the manual zip, then in Steam set HUMANKIND → Properties → Launch options to WINEDLLOVERRIDES="winhttp=n,b" %command%.

Problems?

Report bugs and ask questions on GitHub issues.

Uninstall

Windows Settings → Apps → “Realpolitik: Living Nations for HUMANKIND”. It asks whether to keep your settings and keys. Saves keep opening without the mod, except saves with more than 10 empires, which need MoreEmpires.
